startup-web-archive-pipeline

Python pipeline that rebuilds the historical web record of a list of startups from the Internet Archive's Wayback Machine.

It was developed for a doctoral research project on the Start-Up Chile program (2010-2025). The code is generic: it takes a list of startups with their domains and produces, per archived snapshot, a screenshot, the raw HTML, extracted text, formal measurements, declared typography and lexical tables.

Cristian Aguilar
Doctorate in Design, Universidad de Palermo

Status

The pipeline has been run on the full Start-Up Chile cohort: 1,268 startups, 1,131 with archived snapshots, and a universe of 7,337 startup-year pages (2010-2025), most of them already captured.

What it does

  1. Looks up which years each domain has an archived snapshot (CDX API, one HTTP 200 snapshot per year).
  2. Captures a full-page screenshot of each snapshot with Playwright (Chromium, 1440 px wide, device scale 2, Wayback toolbar hidden, empty or black captures discarded).
  3. Downloads the raw archived HTML (id_ URLs, no Wayback rewriting) and extracts title, meta description, headings, buttons, action links, images and visible text into one JSON per snapshot.
  4. Measures each capture: image size, five dominant colors, distinct colors, counts of images, forms and form fields, visible characters.
  5. Reads the font families declared in the archived HTML and assigns them to broad typographic groups.
  6. Builds frequency, series, shared-term and co-occurrence tables from the extracted text.
  7. Produces contact sheets and per-year color palettes.

Design principles

  • Resumable. All steps can be interrupted and run again.
  • Append-only. Steps add to what already exists.
  • Versioned outputs. Derived outputs keep their previous version in a historial/ folder.
  • Rate-limited requests. Requests to web.archive.org are rate-limited by ritmo_archivo.py, which backs off when the archive refuses connections and remembers the pace that worked.
  • Traceable to each snapshot. Each page is referenced by its Wayback Machine URL and 14-digit timestamp.
